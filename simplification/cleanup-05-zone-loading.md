## Issues / notes

1. **Deviation from report (Finding 2): the AssetServer polling path was NOT deleted.** The report claimed the `loading_via_async_task: false` branch and the first `Spawned` arm are dead. Analysis shows the "cached but not spawned" else-branch in `zone_loader_system` (systems.rs:285-303) IS statically reachable: `zone_loaded_from_vfs_system` despawns all cached zones with `spawned_entity.take()` (leaving cache entries `Some { handle, None }`), so a later `LoadZoneEvent` for a previously-visited zone lands in the else-branch → polling branch → (per Bevy 0.18 `get_load_state` source: `None` for handles added via `Assets::add`) warn + remove. Since it executes observable code (the warning log / queue removal) and is not provably unreachable, per the task's "must be verified unreachable before deleting" rule it was kept, along with the first `Spawned` arm and `LoadingZone.zone_assets`/`clear_asset_handles`. Only the second (duplicate-pattern) `Spawned` arm was provably unreachable and was deleted. If a future pass wants this removed, the else-branch itself must first be changed to reload via the async path (a behavior change, since today the zone silently fails to spawn in that scenario).
2. **`unsafe` removal changed no behavior**: `Assets::remove`/`insert` round-trip is contained within each system execution; the asset is always back in `Assets<ZoneLoaderAsset>` before the system returns, and concurrent readers are serialized by `ResMut`.
3. **`format_bytes` now lives in exactly one place**: `vfs_asset_io::format_bytes` (pub); `loading.rs` and `memory_monitor::log_memory_status` call it.
4. **Wind-sway, boats, terrain pipelines, audio: untouched.** `spawn_new_terrain`/`.mesh.bin` path still fully functional (reachable via `main.rs:224`).
5. `cargo check` was run; all owned files are clean (no errors, no warnings). Remaining errors belong to other agents: `bundles/ability_values.rs`, `scripting/lua_game_constants.rs`, `ui/ui_admin_menu_system.rs`, `ui/ui_inventory_system.rs`, `ui/ui_minimap_system.rs`, `ui/ui_drag_and_drop_slot.rs`, `ui/ui_widgets/mod.rs`.
6. Audio coordination (optional `spawn_spatial_sound` migration): skipped — `pub fn spawn_spatial_sound` does not exist in `src/audio/mod.rs` at completion time.
